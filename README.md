#### 🔧 Selected systems

- **Lead to WhatsApp in about a minute.** Meta lead ads → sheet poll every minute → personal WhatsApp welcome → contact saved, with lead-ID dedupe so nobody is messaged twice. Live since Oct 2026.
- **Speed-to-lead alerts.** 104 of 153 leads on one account were never reached, so I built rotation across salespeople plus an email alert when a lead's status hasn't changed after 5 minutes.
- **Silent-failure audit.** A cash-on-delivery confirmation flow (n8n + Shopify + WhatsApp) reported *success* while dropping orders. I traced and recovered all 3, then shipped retries on all 13 external-call nodes.
- **Voice note → finished reel.** Telegram voice note → research → script → human approval → 1080×1920 reel. Seven modules on one Airtable base; 3m 50s for a verified run.
- **Zero-loss server migration.** 63 workflows, 30 credentials, 11 data tables and 11,883 rows moved with IDs preserved, after rehearsing the destructive step on a restored backup.

> Audit what the system did, not what its dashboard says.
